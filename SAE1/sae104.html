SAÉ 1.04 – Se présenter sur Internet
BUT R&T · Semestre 1 · Projet individuel

Contexte & Objectifs

L'objectif de cette SAÉ était de créer un site web personnel pour se présenter sur Internet. J'ai choisi de réaliser un site thématique autour d'Assassin's Creed appelé « Le Credo », qui inclut aussi une page « À propos » où je me présente. Le site a été codé entièrement à la main en HTML et CSS, sans template ni générateur, et hébergé sur GitHub Pages.

Lien du site : ziane251.github.io/Projet-SAE-14

Apprentissages Critiques (AC) concernés

AC13.01
Utiliser un système informatique et ses outils — j'ai utilisé VS Code, Git et GitHub Pages pour développer, versionner et héberger le site.
AC13.04
Se présenter sur Internet — j'ai conçu un site web complet avec une page de présentation personnelle, une navigation claire et un design soigné.

Tâches réalisées (Contribution personnelle)

  • Conception de la charte graphique : thème sombre, couleurs rouge/noir inspirées de l'univers Assassin's Creed, typographie et mise en page travaillées.
  • Écriture de la structure HTML complète : page d'accueil, page « L'Univers ASC » (avec les différentes époques des jeux), page « À propos » (présentation personnelle) et page « Contact ».
  • Mise en forme CSS à la main : hero banners avec images de fond, grille de cartes pour les jeux, navigation responsive avec menu burger.
  • Hébergement sur GitHub Pages et gestion du code avec Git.
Difficultés rencontrées
  • Le responsive : le menu burger ne fonctionnait pas correctement sur la page « L'Univers ASC », et l'affichage mobile posait problème sur certaines sections.

Résultats obtenus / Preuves et traces

Page d'accueil — « Le Credo » — Hero banner avec le thème Assassin's Creed Unity, navigation et section de présentation de la saga.
Contenu — Les époques des jeux — Grille de cartes présentant les différentes ères : Antiquité, Renaissance, Révolutions, Orient et Asie.
Page « À propos » — Présentation personnelle : qui je suis, mon parcours en BUT R&T et le contexte du projet.
Extrait du code HTML — Le site est codé entièrement à la main, sans framework ni template.

Autoévaluation & Démarche réflexive

Difficulté rencontrée Ce que je ferais si c'était à refaire
Le responsive : le menu burger ne s'affichait pas bien sur la page « L'Univers ASC » et certaines sections passaient mal sur mobile. Partir d'une approche mobile-first dès le départ au lieu de tout faire en desktop puis adapter après. Tester sur téléphone plus tôt dans le développement.
Ce que j'ai appris & positionnement

Ce projet m'a permis de consolider mes bases en HTML/CSS et de découvrir le workflow complet d'un site web : de la conception du design au déploiement sur GitHub Pages en passant par le code et le responsive. Mon expérience en graphisme m'a aidé pour la partie visuelle, mais j'ai appris que rendre un site beau sur desktop ne suffit pas — il faut penser au mobile dès le début. C'est aussi la première fois que j'utilisais Git et GitHub pour héberger un projet. Je me positionne à un niveau satisfaisant : le site est en ligne, fonctionnel et visuellement abouti, mais le responsive reste à perfectionner.
