SAÉ 1.05 – Traiter des données
BUT R&T · Semestre 1 · Binôme : Aghiles & Thibaut

Contexte & Objectifs

Le but de cette SAÉ était de créer des outils en Python pour récupérer, traiter et présenter des données issues de la base OpenStreetMap. Le projet se découpait en deux parties : d'abord un script fiche_osm.py qui génère une fiche HTML sur un point d'intérêt (restaurant, commerce…), puis un script infos_locales.py qui récupère tous les objets d'un certain type dans une ville et calcule des statistiques. Avec Thibaut, on a choisi de travailler sur les arrêts de bus : lister tous les arrêts d'une ville et analyser leurs équipements (abri, banc, éclairage, accessibilité…).

Apprentissages Critiques (AC) concernés

AC13.01
Utiliser un système informatique et ses outils — j'ai utilisé Python, pip, la bibliothèque requests et l'API Overpass pour automatiser la récupération de données.
AC13.02
Lire, exécuter et corriger un programme — j'ai écrit et débugué des scripts Python qui font des requêtes HTTP, manipulent du JSON et génèrent du Markdown/HTML.
AC13.03
Traduire un algorithme dans un langage donné — j'ai traduit en Python la logique de requêtage Overpass QL et le calcul de statistiques sur les arrêts de bus.
AC13.04
Connaître l'architecture d'un site Web — le projet génère des fichiers HTML à partir de Markdown, ce qui m'a fait comprendre la structure d'une page web et le rôle du balisage.
AC13.05
Choisir les mécanismes de gestion de données — j'ai choisi d'utiliser des dictionnaires Python et du JSON pour stocker et manipuler les données OSM.
AC13.06
S'intégrer dans un environnement de travail collaboratif — j'ai travaillé en binôme avec Thibaut, on s'est réparti les fonctions et on a partagé le code.

Tâches réalisées (Contribution personnelle)

  • Écriture du module md_to_html.py : fonction de conversion Markdown → HTML avec la bibliothèque markdown.
  • Écriture de fiche_osm.py : requête sur l'API REST OpenStreetMap, récupération des données JSON d'un nœud, génération d'une fiche Markdown et HTML.
  • Écriture de infos_locales.py : requête Overpass QL pour récupérer tous les arrêts de bus d'une ville, calcul de statistiques (nombre et pourcentage d'arrêts avec abri, banc, poubelle, éclairage, accessibilité handicapé, dalles podotactiles, horaires affichés), et génération d'un rapport Markdown/HTML.
  • Le script est utilisable en ligne de commande : python3 infos_locales.py Caen rapport.
Difficultés rencontrées
  • Trouver un sujet pertinent et intéressant : on a hésité avant de se décider sur les arrêts de bus, qui avaient assez de données et de propriétés pour faire des stats.
  • Le projet était long : beaucoup de fonctions à implémenter et de documentation à lire (API OSM, Overpass QL, bibliothèque requests).

Résultats obtenus / Preuves et traces

Résultat HTML — Statistiques des arrêts de bus d'Ifs — 78 arrêts analysés : 44% avec abri, 38% avec banc, 26% avec poubelle, 14% accessibles en fauteuil roulant. Chaque arrêt est listé avec ses équipements.
Code source — infos_locales.py dans VS Code — Requête Overpass QL, fonctions documentées avec docstrings, calcul des statistiques.
